Stacje Meteorologiczne IMGW

Interaktywna mapa danych ze stacji meteorologicznych IMGW-PIB. Dane obejmują temperaturę, wilgotność, wiatr, punkt rosy, z interpolacją przestrzenną i izoliniami.

Otwórz Dashboard Stacji IMGW

Aktualizacja danych (Pipeline)

Aby odświeżyć dane jednorazowo, uruchom w terminalu:

  1. python pobierz_imgw.py - pobiera najnowsze dane ze stacji
  2. python generuj_dashboard.py - generuje na nowo plik HTML

Ciągła aktualizacja

Możesz uruchomić skrypt python pobieraj_w_tle.py, aby pobierać dane w tle. Proces ten automatycznie co 5 minut uaktualnia informacje ze stacji, zapewniając ciągłość danych na żywo.
